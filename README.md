# ChanBlake Games Homepage

A multi-game homepage for `chanblake.github.io`.

## Game routes

- `/pente/`
- `/chess/`
- `/checkers/`
- `/four-in-a-row/`
- `/reversi/`
- `/gomoku/`
- `/mancala/`
- `/dots-and-boxes/`

Each card is presented as a live game and links to the matching GitHub Pages project route. Pente works with the existing `pente` repository. Create future repositories with the matching names to activate the remaining links.

## Deploy

Upload `index.html` and `styles.css` to the root of the `chanblake.github.io` repository, then commit and push.
