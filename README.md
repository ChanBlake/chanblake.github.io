# ChanBlake Games

The static game library published at `chanblake.github.io`.

## Emberfall: Last Light

The mobile-first roguelite lives in `emberfall/`. A complete run crosses three stages—the Cinder Outskirts, Sunken Road, and Crown's Shadow—with a distinct boss at the end of each. It is dependency-free and uses Canvas, Web Audio, local storage, and an optional service worker. Open `emberfall/index.html` through a local web server to test it, or publish the repository through GitHub Pages and visit `/emberfall/`.

## Junkyard Empire

The pixel-art restoration sim lives in `junkyard-empire/`. Buy procedurally generated auction cars, diagnose eight mechanical systems, choose repair tiers, detail or paint the finished build, and take it through a condition-sensitive test drive before selling to competing buyers. The garage, mechanic, repair effects, traffic, and title scene are drawn and animated in Canvas. Progress, shop upgrades, records, and reputation unlocks are stored locally. Visit `/junkyard-empire/?debug` for the browser test API.
